# Scorched Earth

![Scorched Earth](https://github.com/GbanQ/Scorched-Earth/wiki/images/logo-text.png)

**Scorched Earth** — хардкорный мод на выживание в постапокалиптическом мире, охваченном радиацией. Игрок начинает в герметичном подземном бункере — единственном безопасном месте в враждебной, заражённой радиацией пустоши.

Управляйте ограниченными ресурсами, улучшайте убежище, создавайте защитное снаряжение и боритесь за выживание в смертельной среде.

## Как устроено выживание

1. **Спавн в бункере.** Вы начинаете в герметичном подземном убежище. Снаружи — радиация, внутри — ограниченные запасы и обесточенные системы.
2. **Запуск систем.** Оживите энергосеть, включите вентиляцию, дайте свет.
3. **Прокачка бункера.** Через интерфейс BCU улучшайте базовый модуль — он повышает энергоёмкость, открывает новые крафты и модули.
4. **Открытие модулей.** Медицинский, тепличный, складской модули и мастерская делают бункер самодостаточным.
5. **Вылазки в мир.** Биомы, структуры и ресурсы — только на поверхности, и только в защитном костюме.
6. **Выживание и рост.** Еда портится, воздух заражается, зомби плюются кислотой. Чем глубже вы в прогрессе — тем дальше можете уходить.

## Ключевые системы

| Система | Описание |
|---|---|
| Новое измерение | Выжженный мир с уникальными биомами, небом и погодой |
| Радиация | Накапливается в опасных зонах, отравляет тело, лечится в бункере |
| Бункер | Строительство, защита блоков ядром, герметичные двери, обшивка |
| Энергосистема | Генераторы, солнечные панели и единая сеть через BCU |
| Модули бункера | Медицинский, тепличный, складской, мастерская — прокачиваются до 3 уровня |
| Защитные костюмы | Полевой и химзащита с зарядом, улучшения в кузнице |
| Промышленные плантеры | Автоматические фермы на энергии бункера |
| Консервирование | Еда портится — консервируй урожай впрок |
| Споровые зомби | Мобы пустоши с кислотными плевками |
| Структуры | Радиоактивные оазисы с изоталитными кристаллами, вулканы, базальтовые шпили |
| BCU AI | Встроенный искусственный интеллект бункера: квесты, справка, телеметрия |
